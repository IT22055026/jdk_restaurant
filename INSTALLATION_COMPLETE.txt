❓ FREQUENTLY ASKED QUESTIONS:

Q: Do customers need to login?
A: No! It's completely public and login-free.

Q: How do orders appear in POS?
A: Automatically! When customer places order, it creates
   an order in your POS system immediately.

Q: Can I customize the menu look?
A: Yes! Edit resources/views/qr-menu/menu.blade.php

Q: What if QR code doesn't scan?
A: Make sure it's printed clearly (dark on white).
   The QR code is generated automatically.

Q: Do I need to update QR code if menu changes?
A: No! QR code is fixed. It always points to latest menu.
   Change products/prices in admin → menu updates automatically.
